WealthCompass

A free-first investment companion making risk, portfolios, financial goals and market context understandable for beginner investors.

The problem

Most investment tools assume financial fluency. Beginners need explanations, planning support and portfolio feedback without immediately requiring paid data or broker integrations.

The solution

WealthCompass combines onboarding, risk profiling, education, portfolio tracking, multi-goal planning, market context and mentor guidance in a local-first workspace.

Profile → Risk score → Learning → Portfolio → Health rules → Goals → Market context → Mentor → Cloud sync

Product flow

Four primary product views show how the workspace moves from a single financial command center to portfolio detail, disciplined goal funding, and a portfolio-first market read.

Architecture

Application

Next.js + TypeScript

Componentized dashboard workflows and route handlers.

Data

Local-first + Supabase

Useful without credentials, with authenticated cloud sync when configured.

Intelligence

Rules before AI

Deterministic risk, health and goal engines provide reliable fallbacks.

Quality

Testable domain logic

Extracted modules cover scoring, imports, mappings and planning.

Key decisions

Free-first operation

Local storage and fallback market data keep the product demonstrable without external accounts.

Portable user data

CSV and JSON import/export, statement review and transaction history reduce lock-in.

Defensive integration

Normalized inputs, mapping tests and sync states make external failures visible and recoverable.

Engineering evidence

Testing scope314 tests · 46 files

Rules, imports, OAuth state, broker and inbox adapters, Supabase mapping, cloud sync and two Playwright journeys are represented.

API surface19 route handlers

Server boundaries cover risk, imports, market snapshots, mentor, broker connections, inbox connections and scheduled synchronization.

Security controlsSigned OAuth state

HMAC-verified OAuth state, server-only provider secrets, Supabase authentication and RLS-ready data modeling constrain integration access.

Reliability observationLocal-first fallback

Core portfolio, risk and goal workflows remain useful when cloud, market or AI providers are absent or unavailable.

Architecture trade-offResilience over simplicity

Local and cloud modes reduce external dependency risk, but require explicit hydration, reconciliation and visible sync states.

CI/CD checks4 quality gates

GitHub Actions runs clean installation, linting, the test suite and a production Next.js build on pushes and pull requests.
