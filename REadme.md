# Aashritha N — Portfolio
Recruiter-focused static portfolio. No build step required.

Contact details, experience, credentials, education, project links, and the downloadable résumé are populated. Before publishing, verify that every credential date and ID is current and add a direct credential-verification URL when available.

Preview with `python3 -m http.server 8000`. Deploy directly to GitHub Pages, Netlify, or Vercel.
