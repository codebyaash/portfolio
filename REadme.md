# Aashritha N — Portfolio
Recruiter-focused static portfolio. No build step required.

Contact details, experience, verified credential links, education, project case studies, architecture diagrams, and the downloadable résumé are populated.

Privacy-first interaction analytics are implemented through `analytics.js`. See [ANALYTICS.md](ANALYTICS.md) for activation, event definitions, and privacy constraints.

Preview with `python3 -m http.server 8000`. Deploy directly to GitHub Pages, Netlify, or Vercel.
